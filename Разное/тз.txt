ТЗ: Мульти-Таймфреймный дашборд EURUSD (MT5 + LightGBM)
1. Назначение
Интерактивный дашборд для визуализации и пошагового тестирования LightGBM-моделей на разных таймфреймах (5m, 10m, 15m, 30m, 60m) по паре EURUSD с данными MetaTrader 5.

2. Источник данных
MT5: copy_rates_from_pos("EURUSD", TIMEFRAME_M5, 0, 15000)
Фильтр: только будни (dayofweek < 5)
Ресэмплинг M5 → 10m, 15m, 30m, 60m (OHLC: first/max/min/last)
3. Целевая переменная
Гауссова конволюция (scipy.ndimage.gaussian_filter1d, sigma=5) по close
Target: delta_gauss.shift(-1) — изменение сглаженной цены на 1 бар вперёд
Модели предсказывают delta_gauss (не уровень цены)
4. Признаки (features)
Для каждого TF строятся одинаковые лаговые признаки:

gc_lag_1..10 — лаги гауссовой конволюции
open_dif_1..10, high_dif_1..10, low_dif_1..10, close_dif_1..10 — лаги разностей OHLC
Все признаки — .shift(1) (только прошлое, нет утечек)
5. Модели
LightGBM Regressor (n_estimators=200, max_depth=5, lr=0.05)
Отдельная модель на каждом TF: 5m, 10m, 15m, 30m, 60m
Обучение на последних N барах (настраиваемо в сайдбаре):
5m: 100–1000 баров (default 300)
Старшие TF: 50–500 баров (default 150)
6. Live-симуляция (пошаговая)
Cut: последние 100 баров 5m откладываются под тест
Кнопка «Следующий бар ➡️» — добавляет 1 бар из тестового набора
Кнопка «Сброс 🔁» — возвращает к началу
При каждом шаге:
Обновляется полный датафрейм (train + увиденные тестовые бары)
Пересчитывается GAUSS и MA20 на всем окне
Для каждого TF находится последний завершённый бар по времени
Модель TF выдаёт предсказание delta_gauss для этого бара
Предсказания накапливаются в истории
7. Визуализация (один синхронизированный график)
Подграфик	Высота	Содержимое
1 (верх, 70%)	70%	Свечи (opacity 0.7) + MA20 (оранжевая линия)
2 (низ, 30%)	30%	Линии delta_gauss предсказаний 5 моделей: 5m🔵, 10m🔴, 15m🟢, 30m🟣, 60m🟤 + нулевая линия
Shared X-axis — синхронный зум/скролл
Rangebreaks — скрыты выходные (sat–mon)
Нет заголовков — компактное размещение
8. Таблица текущих сигналов
Под графиком — DataFrame с последними delta_gauss по всем 5 TF (формат 0.000001).

9. Технологический стек
MetaTrader5 — данные
pandas, numpy — обработка
lightgbm — модели
scipy.ndimage.gaussian_filter1d — конволюция
plotly (make_subplots) — интерактивные графики
streamlit — веб-интерфейс
10. Запуск
streamlit run dashboard.py
Требуется запущенный терминал MT5 с доступом к EURUSD M5.
